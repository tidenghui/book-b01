# 灶王爷的眼泪

> 凡间一锅烟火，阴间万里黄泉，他只想让她再尝一口。

**题材**：仙侠 · 美食 · 温情虐心　**作者**：灯下人　**12 章 · 33,632 字**

凡厨陈勺误入修仙界，发现自己炒的菜能让死人短暂回魂。为再见亡妻阿绣一面，他参加六十年一届的阴间厨神大赛。七天里用凡间食材做出让阎王落泪的菜。对手是仙厨、鬼厨、妖厨。他一路靠家常菜过关，最后做出阿绣生前最拿手的糖醋排骨。她尝后微笑消失。他从此再也做不出那道菜，却成了阴间永远的第末位厨神。
